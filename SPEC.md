# Loomis

Loomis — локальная система управления проектами и агентами разработки. Пользователь передает технические задания через Telegram-бота или API, отслеживает состояние обработки и получает результаты.

## Архитектура

- **FastAPI backend** предоставляет HTTP API и WebSocket для состояния задач и realtime-обновлений.
- **Aiogram bot** принимает сообщения и документы Telegram, связывает аккаунт пользователя с локальным Loomis.
- **Database** использует асинхронный SQLAlchemy и SQLite для пользователей, одноразовых токенов привязки, проектов, пунктов спецификации и конфигурации агентов.
- **Core/worker** обрабатывает задания и интеграции агентов; отдельные каталоги `workspaces/` и `temp_uploads/` предназначены для рабочих копий проектов и временных загрузок.
- **Desktop client** служит локальным пользовательским интерфейсом к API.

Все компоненты работают локально по умолчанию. Настройки, включая адрес API, токен Telegram, ключ приложения и строку подключения БД, задаются переменными окружения.
